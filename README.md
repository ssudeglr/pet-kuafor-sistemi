# 🐾 Pet Kuaför Yönetim Sistemi

Bu proje, evcil hayvan kuaförleri ve pet shoplar çalışanları için takibini kolaylaştırmak amacıyla geliştirilmiş bir yönetim sistemidir.

## 🚀 Özellikler
- **Müşteri Yönetimi:** Müşteri kaydı oluşturma, düzenleme ve silme.
- **Evcil Hayvan Kaydı:** Evcil hayvanların bilgilerinin takibi.
- **Veritabanı Entegrasyonu:** Dinamik veri yönetimi.

## 🛠️ Kullanılan Teknolojiler
- **Backend:** Python / Flask
- **Veritabanı:** SQLite
- **Frontend:** HTML5, CSS3
